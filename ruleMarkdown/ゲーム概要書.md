# ゲーム概要

## タイトル
**RikuLove Neglect**

---

## ジャンル
地雷放置系ノベルゲーム

---

## コンセプト
地雷系彼女との同棲生活を送りながら、
プレイヤーの行動によって彼女の「親愛度」や「病み度」などのパラメータが変化する。

さまざまなイベントやエンディングを通して、すべてのエンドの回収を目指す。

---

## 世界観
- 現代日本
- 主人公は社会人
- 地雷系彼女と同棲している

---

# ゲームシステム

メイン画面では以下の4つのメニューを選択できる。

## ホーム
- 彼女との日常会話
- パラメータ確認
- その他ホーム関連機能

## デート
- デート先を選択
- 行き先によってイベントやパラメータが変化

## スキンシップ
- 彼女との触れ合いを行う
- 行動によって各種パラメータが変化

## その他
- 設定
- エンディング一覧
- タイトルへ戻る

---

# セーブ仕様

- セーブ・ロードはオートセーブのみ
- プレイヤー名はゲーム開始時に一度だけ設定可能
- 名前は後から変更不可

---

# パラメータ

| パラメータ | 内容            |
| ----- | ------------- |
| 親愛度   | 彼女からの好意を表す値   |
| 病み度   | 精神状態・依存傾向を表す値 |
| 鬱モード  | 鬱状態の進行度       |
| PMモード | 特殊状態（詳細は別仕様）  |
| 季節    | 春夏秋冬          |

---

# エンディング

| 種類         |     数 |
| ---------- | ----: |
| 特殊バッドエンド ¹ |     6 |
| 通常バッドエンド   |     8 |
| トゥルーエンド    | 2（予定） |
| ハッピーエンド    |    未定 |
¹ 何か一つ行動を挟まないと到達できないend

---

# 対応プラットフォーム

- Windows
- Android

# 開発メモ

- エンディング数は開発状況に応じて変更の可能性あり
- PMモードの詳細仕様は別ドキュメントに記載予定
- 普通にゲーム性が変わる可能性あり
- ゲーム設定・設計などはここに従う事
