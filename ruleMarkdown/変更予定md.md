## 機嫌
- 彼女の機嫌を追加
- ホーム画面のステータス見れるところで見れる
- 病み度が3回上がると機嫌ダウン
- 親愛度が3回上がると機嫌アップ
- 病み度が下がると機嫌アップ判定になる

機嫌には五段階ある

|        |                                                   |
| ------ | ------------------------------------------------- |
| 上機嫌     | 最高に気分が良い。親愛度が上がりやすく、病み度が上がりにくい<br>倍率 : 親愛度 0.5分上がる　->　例 __親愛度 += 5 + (5 * 0.5)__ <br>　　　病み度 0.5分引く　->　例 __病み度 += 5 - (5 * 0.5)__ 、__病み度 += -5 - (5 * 0.5)__　　(x * 0.5)のxは絶対値|
| ご機嫌     | 普通に機嫌が良い。上機嫌時の倍率が0.25倍となる|
| 通常     | 普通の機嫌。補選はかからない|
| ご機嫌斜め     | 普通に機嫌が悪い。上機嫌時の倍率が-0.25倍となる|
| 不機嫌     | 最高に気分が悪い。上機嫌時の倍率が-0.5倍となる |
